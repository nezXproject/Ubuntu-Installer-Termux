🚀 Cara Install (Otomatis)

Buka Termux, copy-paste perintah ini, tekan Enter:

pkg install -y git && git clone https://github.com/nezXproject/Ubuntu-Installer-Termux.git && cd Ubuntu-Installer-Termux && bash termux-ubuntu-installer.sh

Tunggu 10–20 menit. Script akan otomatis:

  • ✅ Cek perangkat & storage
  • ✅ Download Ubuntu (~500 MB)
  • ✅ Extract rootfs
  • ✅ Konfigurasi DNS
  • ✅ Buat launcher script

🎯 Cara Masuk ke Ubuntu

~/startubuntu.sh

Prompt akan berubah jadi:

root@localhost:~#
🎉 Selamat! Kamu sekarang di Ubuntu!

Untuk keluar:

exit

📦 Setup Pertama Kali

Setelah masuk Ubuntu, jalankan:

apt update && apt upgrade -y
apt install -y build-essential git python3 python3-pip nano vim curl wget net-tools

Buat user biasa (opsional, disarankan):

adduser ubuntu

🔧 Troubleshooting

MasalahSolusi
❌ "Kernel too old"Edit ~/startubuntu.sh, ubah PROOT_ARGS="" jadi PROOT_ARGS="-k 4.14.81"
❌ "No space left"Butuh 3 GB kosong. Hapus: rm -rf ~/ubuntu-fs lalu install ulang
❌ "proot: command not found"pkg install proot -y
❌ Network tidak jalanDi Ubuntu: echo "nameserver 8.8.8.8" > /etc/resolv.conf
❌ Lambat / lagNormal. PRoot memang lambat. Tutup aplikasi lain.

🗑️ Cara Uninstall

bash ~/uninstall-ubuntu.sh
⚠️ Semua data di Ubuntu akan hilang permanen.
